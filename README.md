# Skilled Nursing Facility Reimbursement

Healthcare billing platform calculating Medicare reimbursements based on patient acuity, therapy minutes, and diagnosis codes.

## Overview

Blockchain-based system for managing skilled nursing facility (SNF) reimbursements, ensuring accurate Medicare billing through RUG (Resource Utilization Groups) classification, therapy documentation, and regulatory compliance.

## Key Features

### Patient Assessment
- MDS (Minimum Data Set) documentation
- RUG-IV classification
- ADL (Activities of Daily Living) scoring
- Clinical diagnoses tracking
- Comorbidity documentation

### Therapy Documentation
- Physical therapy minutes tracking
- Occupational therapy documentation
- Speech-language pathology services
- Group vs individual therapy classification
- Concurrent therapy tracking

### Reimbursement Calculation
- Per diem rate determination
- RUG category-based rates
- Therapy threshold compliance
- Urban/rural adjustment factors
- Case-mix index calculations

### Revenue Management
- Daily billing records
- Claim submission tracking
- Payment posting
- Denial management
- Revenue cycle optimization

### Compliance Monitoring
- Medicare Part A requirements
- Therapy minute thresholds
- Documentation standards
- Audit trail maintenance
- Regulatory reporting

## Smart Contract

### nursing-reimbursement-calculator
- Register patients and assessments
- Track therapy service delivery
- Calculate RUG classifications
- Determine reimbursement rates
- Submit and track claims
- Monitor compliance metrics
- Maximize facility revenue
